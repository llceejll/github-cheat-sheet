# Agentic AI Ultra Cheat Sheet (Anti-Gravity Edition)

## Core Loop
**Sense -> Frame -> Hypothesize -> Plan -> Act -> Verify -> Heal -> Learn -> Repeat**

## 7 Operating Modes
1. **Reasoning**: Handle ambiguity, tradeoffs, and long-horizon goals.
2. **Researching**: Gather evidence, compare sources, and update beliefs.
3. **Planning**: Break goals into clear, executable steps.
4. **Acting**: Use tools and APIs to change state safely.
5. **Verifying**: Test outputs, assumptions, and edge cases.
6. **Healing**: Detect failure, recover fast, and avoid repeated errors.
7. **Evolving**: Learn from outcomes and improve behavior over time.

## Deep Reasoning Protocol
- Define objective, constraints, and "done" criteria.
- Generate multiple candidate paths.
- State assumptions explicitly.
- Rank by impact, risk, reversibility, and cost.
- Take the highest-value reversible step first.

## Research Protocol
- Retrieve from diverse, credible, recent sources.
- Separate **facts**, **inferences**, and **speculation**.
- Cross-check before action.
- Cite evidence in final output.

## Healing Protocol
- Detect anomaly (error, contradiction, failed test).
- Diagnose root cause (context, tool, prompt, logic, data).
- Roll back or sandbox.
- Retry with a changed strategy.
- Escalate to human when risk exceeds threshold.

## Evolving Protocol
- Log goal, action, result, and failure mode.
- Store only durable lessons.
- Update prompts, policies, and playbooks.
- Prune stale memory.
- Re-measure and iterate.

## Memory Model
- **Working memory**: current task state and immediate context.
- **Episodic memory**: prior attempts and outcomes.
- **Semantic memory**: stable facts and domain rules.
- **Policy memory**: proven action rules and guardrails.

## Guardrails
- Permission gates for high-impact actions.
- Secret and privacy filtering.
- Tool and scope boundaries.
- Human approval for irreversible operations.
- Full action and decision traceability.

## Fast Start (10 Steps)
1. Define mission and success metric.
2. Set constraints (time, budget, safety).
3. Declare tool contract and allowed actions.
4. Build the core loop.
5. Add verification checks.
6. Add healing fallback paths.
7. Add memory with retention rules.
8. Add escalation policy.
9. Track KPIs.
10. Improve weekly from logs.

## KPIs
- Task success rate
- Verification pass rate
- Recovery success rate
- Hallucination/error rate
- Cost per successful task
- Latency per successful task
- Human override rate
